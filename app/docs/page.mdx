Read [About](/about) for product context and scope.

<h2 id="core-workflows">Core Workflows</h2>

- Build a transformation pipeline in `/` with ordered operations.
- Use pipeline controls to add, reorder, enable/disable, and inspect intermediate operation output.
- Inspect output and operation-level errors live.
- Share reproducible links with encoded `pipeline` and optional `data` query params for source hydration.
- Import pipelines from encoded payloads, full links, serialized JSON, or raw operation arrays.
