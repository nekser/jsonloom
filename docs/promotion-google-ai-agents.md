# Automated Promotion Plan (Google + AI Agents)

Date: March 8, 2026  
Scope: non-social promotion only (fully automated or one-time setup + automation)

## Current SEO State (from current app layout)

- Basic metadata exists in `app/layout.tsx` and `app/about/page.tsx`.
- The home page (`/`) is primarily app UI, so crawlable keyword/context content is limited.
- No `robots.txt` metadata route (`app/robots.ts`) detected.
- No `sitemap.xml` metadata route (`app/sitemap.ts`) detected.

## Highest-Impact Automation Plan

1. Add `robots.txt` and `sitemap.xml` via Next.js metadata routes.
2. Submit sitemap in Google Search Console once, then auto-resubmit on deploy with Search Console API.
3. Add IndexNow ping on deploy/content updates (fast discovery for Bing and participating engines).
4. Add canonical URLs + `metadataBase` + JSON-LD (`SoftwareApplication`, `WebSite`, `Organization`).
5. Add a short crawlable landing section on `/` (problem, features, use cases, links to docs/about).
6. Add recurring indexability checks in CI (status `200`, no accidental `noindex`, sitemap URL integrity).

## AI-Agent Discoverability (Automated)

1. Explicitly allow AI search crawlers in `robots.txt`:
   - `OAI-SearchBot`
   - `ChatGPT-User`
   - `Claude-SearchBot`
   - `PerplexityBot`
2. Optional policy split: allow AI search crawlers but block AI training crawlers:
   - Block examples: `GPTBot`, `ClaudeBot`
3. Keep docs static, linked, and example-driven so retrieval agents can extract precise answers.

## Implementation Blueprint for Current Routes

For the current route set (`/`, `/docs`, `/about`):

1. Create `app/robots.ts`
   - Allow core site crawling.
   - Add explicit AI crawler rules.
   - Point to sitemap URL.
2. Create `app/sitemap.ts`
   - Include only canonical, indexable URLs for `/`, `/docs`, `/about` and stable docs subpages.
   - Set accurate `lastModified`.
3. Strengthen metadata in `app/layout.tsx`
   - Add `metadataBase` (production domain).
   - Add default canonical behavior and social preview fields (for snippets, even without social campaigns).
4. Add per-page metadata where missing
   - Clear intent-driven titles/descriptions for `/` and `/docs`.
5. Add JSON-LD blocks
   - `SoftwareApplication` on `/`
   - `WebSite` and `Organization` site-wide or on `/about`
6. Add deploy-time automation
   - Google sitemap submit API call.
   - IndexNow URL submission/ping.
7. Add CI validation job
   - Fail build if pages become `noindex`, return `500`, or are missing from sitemap.

## Practical `robots.txt` Policy Shape

Use this as policy intent (final syntax generated by `app/robots.ts`):

```txt
User-agent: *
Allow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: Claude-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

# Optional training blocks
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

Sitemap: https://<your-domain>/sitemap.xml
```

## Why This Works

- Google AI features rely on standard Search eligibility; no separate optimization stack is required.
- Sitemaps and clean crawl directives improve URL discovery and update frequency.
- AI answer engines depend on crawlability, stable docs, and structured content signals.
- Automation prevents regressions as routes/docs evolve.
